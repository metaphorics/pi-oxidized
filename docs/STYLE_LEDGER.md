# TUI Terminal Copy Style Ledger (TUI-G5, issue #50)

This is the single authority for terminal copy policy in the pi-oxidized TUI and
CLI. Every axis below resolves to one decision. The rule from EXT-25 (issue
#25) governs every row:
**reference parity is the default** — the TypeScript reference copy (`.references/pi-2.0/…`
at `853a80d26c90a14c1886f0ebb8ffaae133ca2185`) is the canonical behavior authority, every Rust deviation is an explicit, recorded decision, and any divergence
noted here names the downstream ticket that applies it. Copy is a Pass (implementable)
category, not a Route category.

Each `Reference witness` / `Rust witness` cell names a `path:line` and the exact literal
that still exists there today. `scripts/verification/style-ledger.ts` mechanically
re-checks exactly ten axes, one decision per axis, every cited literal at its
named line, and no unsettled-token marker in this file. That gate maps to G1
("zero open items").
